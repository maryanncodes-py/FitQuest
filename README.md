# 💪 FitQuest

FitQuest is an interactive command-line fitness adventure game developed in Python.

The player answers a series of questions about their fitness preferences before embarking on a personalized fitness journey. Throughout the game, the player makes decisions that determine one of several unique story endings.

## Features

- Personalized fitness adventure
- User input validation
- Multiple story paths
- Multiple endings based on player decisions
- Replay functionality
- Interactive command-line experience

## Technologies Used

- Python

## Concepts Demonstrated

- Variables
- User Input
- While Loops
- Conditional Statements
- Functions from the `time` module
- String Formatting (f-strings)
- Program Flow Control

## How to Run

1. Download the repository.
2. Open the project in Visual Studio Code.
3. Run:

```bash
python FitQuest.py
```
